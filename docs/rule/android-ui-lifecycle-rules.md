# PlayTV UI 生命周期、系统栏、键盘与导航

本文件负责本项目 UI 资源生命周期和平台交互。设计单位/资产见 [项目约定](project-conventions.md)，可用类和真实 API 以 [组件目录](ui-component-catalog.md) 与源码为准；适用边界见 [项目基线](project-context.md)。下文不是现成 Dialog/导航栏 API 清单。

## 页面与订阅

- Activity 订阅跟随自身 Lifecycle，Fragment 展示订阅跟随 `viewLifecycleOwner`；用 `repeatOnLifecycle` 在合适状态收集。每次视图重建只注册一组监听，不能叠加旧订阅。
- ViewModel 不持有 View/Binding/宿主引用。Fragment 在 onDestroyView 清理 Binding、关联视图的适配器/回调/控制器；存在外部长寿命监听时必须显式注销，不能仅将字段置空。
- 初始数据加载由明确入口控制，不能放在每次 render 或每次 STARTED 自动执行。可见刷新另行定义；重复订阅不等于新的业务意图。
- 延迟 Runnable、动画、观察器、图片目标和 SDK 回调都有所有者与取消入口。回调返回时验证视图仍有效，不能只检查 Activity 未 finish。
- Dialog、Popup、BottomSheet 明确宿主、展示条件、关闭/取消差别和状态恢复；展示前确认宿主生命周期。不要把 Dialog 实例存在进程单例中。
- 需要跨配置变化恢复的弹窗可评估具备恢复能力的承载方式，按本项目需求决定。先核对已有能力，不直接搬用其他项目自建 Lifecycle/ViewModelStore 实现。

## 系统栏与 Insets

- 区分系统状态栏/导航栏和业务顶部栏/底部栏。顶部设计栏高不包含系统状态栏，不能照抄其他项目固定高度或手写状态栏常数。
- 每个边缘只设一个 Insets 责任方；在初始 padding/margin 基础上计算，不能每次回调继续累加。Fragment 默认由宿主处理系统栏，不能再垫一遍。
- **当前实现**：BaseActivity 配置透明系统栏，BaseMviActivity 委托 SystemBarInsets 应用根视图；可在 initView 重新指定逐边消费，首次 padding 保持不变。不提供动态明暗图标或弹窗适配能力。
- 需要沉浸图片、局部 Header/Footer 或底部面板时，使用 SystemBarInsets.Edges 指定各边消费位置，保证根与局部只消费一次。真正贴底的面板处理底部安全区，整屏遮罩不必一起上移。
- IME 与导航栏 Insets 分开处理，明确 resize/移动/滚动策略，避免系统调整、根 padding 和局部位移叠加。横屏、手势/三键导航、刘海和多窗口均不能靠固定尺寸猜测。
- 编辑页可用 SystemBarInsets.apply(root, includeIme = true)，底边取系统栏与 IME 最大值；默认 false 保持普通页策略。由同一工具替换自身监听并保留首次 padding，销毁时 clear，不叠加另一个根 Insets 监听。
- 系统栏图标明暗由当前背景和可读性决定；若现有基类只有固定策略，新增需求时补充真实能力并更新目录。

## 键盘与触摸

- 自动聚焦、显示/隐藏键盘和点击外部收起是功能策略，按页面启用；不能给所有输入页强加“触摸任意位置清焦点”。
- 软键盘可见时按返回仅收起键盘，保留输入焦点与内容，不同时导航、清空状态或执行其他操作；键盘关闭后的返回按页面正常处理。
- 等 View 附着且可聚焦后请求键盘；页面退出取消待执行显示。操作使用当前 Window/焦点，不保存旧 Activity。
- 外部点击检测保证坐标体系一致，避开输入区和需要保留焦点的操作区；不消费原事件、不随意替换现有 OnTouch/OnClick 监听。
- 控制器销毁时取消回调、注销监听、恢复自己修改的焦点/窗口属性；多个控制器不能争抢全局状态。

## 导航和公共组件

公共 Loading、短暂消息、确认与设置引导的场景选择及构建统一见 [公共反馈](ui-feedback-rules.md)；类名、路径、实际可用状态分别查项目约定、数据契约和组件目录，不在此复制 API 清单。

- 入口参数写明类型、缺省和失效处理；优先传稳定业务 ID，再由目标加载。大对象不塞 Intent/Bundle，敏感凭据不走路由。
- 出口区分成功、返回、取消、失败；Activity Result 的注册和处理跟随宿主生命周期。导航由 UI 消费业务语义，model 不构造 Intent 或引用 app 类。
- 返回键、系统返回手势、点遮罩关闭、显式取消各自含义写入 Spec；未保存修改是否提示由业务决定，不能所有弹窗统一返回成功。
- 公共 View 公开渲染参数、状态和事件回调，不在内部查询全局账号、发业务请求或固定跳转某页面。请求与导航由宿主编排。
- 仅展示重复优先 style/include/merge，有独立交互/状态才抽类；不要为一次性页面先建“万能组件”。列表事件使用稳定标识或校验当前位置，避免捕获过期 position。
- 组件空态、禁用、加载、错误、无障碍描述及资源释放按真实用途说明，不依赖业务页面偷偷补齐。
