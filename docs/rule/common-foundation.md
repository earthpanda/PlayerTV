# PlayTV 公共基础基线

本文件规定公共基础的复用、配置和升级方式。实际能力查 [组件目录](ui-component-catalog.md)，依赖查 [依赖目录](build-dependency-catalog.md)，职责/目录查 [数据契约](data-contract-rules.md)，开发行为查 [公共能力规则](common-capability-rules.md)。

## 一份标准实现

初始化采用原型 0.4.0 的标准源码与规则；[公共基线记录](../../.foundation-baseline.json) 保存所选能力、模板源摘要和项目源码摘要。初始化 lock 记录历史，不通过重复运行初始化器升级已有工程。

后续开发先查本项目组件目录、能力说明与真实 API。已提供的客户端、转换器、错误边界、ImageLoader、存储和生命周期工具直接复用，不按每个需求重新生成同义实现或 Utils2。不要求新增无行为的包装层，也不重复封装 Kotlin/AndroidX 已有能力。

参数通过已提供的配置/构造入口传入；协议差异在 model 的策略/适配器处理。基础实现确有缺陷时，在唯一源码修正，记录原因、影响、边界场景和本地差异。禁止为单接口修改所有接口的业务成功判定，或绕过公共入口私建另一客户端。

## 基础、可选能力与项目策略

默认基础包括工程、设计宽度、AppContainer/StartupStep、基础页面/MVI/Factory、日志、文件/Uri、键盘、Insets 与时间/文本工具。推荐初始化配置选择 network/image/mmkv；用户可以显式省略，对应源码、权限及 SDK 都不生成。SSE、permissions 显式按需选择；preferences 作为旧 DataStore 兼容能力保留，同一数据不双写两种引擎。未启用不能调用其 API，不能自动引入数据库、下载器、账号或厂商 SDK。

基础设施只提供机制：网络传输、解析注册、连接/队列管理、文件操作、权限宿主、设置引擎。端点、DTO、成功码、登录与签名、SSE done、文件内容/保留、权限集合、业务 key 与默认值由项目定义。没有真实需求时不预建全部候选 Manager/Repository。

Manager 的统一部分是职责、所有者、作用域、并发与释放契约；不生成万能 BaseManager、全量启动初始化或全局服务定位器。完整要求只在 [Manager 规则](manager-lifecycle-rules.md) 维护。

## 每项公共实现的交付标准

| 方面 | 必须说明 |
|---|---|
| 命名 | 名称对应行为；时间、尺寸、容量标明单位；纯查询不产生写入副作用 |
| 输入与错误 | 合法范围、null/空值、无数据、预期失败、取消、程序错误的边界 |
| 并发 | 线程要求、重入/重复调用、共享状态同步、旧结果是否还能提交 |
| 生命周期 | 谁创建/持有/关闭，关闭是否幂等，关闭后调用怎样，回调和延迟任务如何取消 |
| 效能 | 不阻塞主线程，客户端按作用域复用，大文件流式处理，不为日志读整包内容 |
| 临界点 | 队列、缓存、事件、文件和日志的边界；超限后拒绝/失败/清理怎样；不默认无限队列 |
| 诊断 | 操作类别、请求标识、状态/耗时、容量与错误类型；无 Token/URL/body/原始异常消息 |
| 完整交付 | 源码、依赖、Manifest/资源/R8、配置、调用示例及实际验证状态 |

数值默认值是统一起点，允许通过已说明的配置调整，不能标成经过业务压测的最优值。瞬时 Effect 队列满时拒绝并记录；SSE 增量片段满载时失败断流，不能静默丢弃后继续宣称完整成功。

## 文件、平台和诊断基础的当前边界

- AppDirectories 返回受控的 files/cache/noBackup 路径，不隐式创建目录；作用域片段显式传入。文件名/目录片段受校验，不把外部展示名直接拼路径。
- AtomicFileStore 一个实例拥有一个目录，writeNew/importUri 在 IO 上执行，64KiB 流式复制，maxBytes 由调用者显式给出。同一实例串行，只写新目标；失败/提交前取消清自己的临时文件。原子移动提交后即为完整文件，若取消恰在提交后发生，调用方仍须按任务文件名核对已提交产物。没有跨进程/多实例目标竞争保证、覆盖/整目录删除、FileProvider 分享或清缓存业务。
- UriAccess 仅处理明确返回的持久读授权标志；不解析“真实文件路径”，不保证每个 provider 都支持持久授权。用户导出、分享、相机、选择器和备份按具体功能接入。
- DiagnosticLog 默认 WARN/ERROR、固定结构化标量和安全分类标识，不持久化/上传。允许配置最低等级；标识只能是无敏感信息的常量，不能把 Token/用户输入放进分类字段。MVI、网络、图片与临时文件清理共用该诊断入口。
- KeyboardController 跟随一个输入框的宿主，close 取消待执行的显示任务；不接管整页触摸，不提供强制重试显示。SystemBarInsets 逐边可配置、保留首次 padding；同一 View 只有一个 Insets 所有者。BaseMviActivity 的 initView 可按需求重新配置根边缘；Fragment 默认由宿主消费。
- TimeFormats 区分 epochMillis 与 durationSeconds，时间戳明确 ZoneId/Locale；时长使用非负累计小时格式。applyFontSizeAndLineHeight 仅处理 pt 字号/行高，不读取业务语言和字号设置。

所有新增基础调用示例位于 src/debug，供阅读和授权后的手动验证，不自动执行、不新增产品页面。示例文件存在不代表已经编译/运行。

## 版本与验证

生成后的工程独立维护自己的准则，继续使用同一套公共职责与扩展方式。业务选择和新增规则写入本项目；公共实现偏离基线时记录原因。采用原型修复时比较公共基线摘要、当前源码和目标版本，只迁移已审阅的变更，不覆盖业务文件、不重写初始化 lock。迁移后的公共基线记录本次采用的版本和实际摘要。

当前版本仅完成源码审阅、配置渲染、结构/文档/依赖方向静态核对。未执行 Gradle、编译、测试、R8 或设备运行；静态核对不能证明功能链路、系统权限或并发行为已运行通过。
