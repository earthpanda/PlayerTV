# GenTV 桌面内容接入

用户已安装 PlayTV 时，GenTV 中的 Gen 视频入口直接打开 PlayTV。PlayTV 的 GHCP 1 内容按“输入分享码、播放记录、搜索”顺序提供三个快捷入口：GenTV 对首项打开自身的分享码输入页，已有链接选择播放源后交由 PlayTV 解析；其余两项进入历史播放源和已保存频道及影片的搜索。这里的记录是当前已有的历史播放源，不表示逐条视频观看历史。不向桌面输出频道、历史、账号或其他私人数据。

入口 Activity 声明协议与同包绑定服务；debug 使用来源入口并处理固定 actionId 的冷启动和新 Intent，忽略未知动作，普通启动和 Activity 重建不重复导航。分享码页属于 GenTV，PlayTV 不直接访问其私有 Activity；旧宿主转发该 action 时提示用户从 GenTV 分享码页面进入。main 使用现有技术预览入口，尚无上述页面，仅提供打开应用。服务只在绑定期间运行工作线程，以 Android 的发送 UID 验证 GenTV 包，回复带原 token 的公开 summary；退出时释放线程。不访问网络、不申请额外权限、不维持前台服务。

变更影响与回归：此前 PlayTV 无 GHCP 声明；安装旧版时 GenTV 只能直接打开应用。需验证覆盖安装后扩展发现、明确授权、首页聚焦和快捷入口，以及普通启动、撤销授权和旧版兼容。设备、遥控与协议端到端结果需单独记录；此前的播放验证不代表本次通过。

本次验证：`-DTest=true :app:compileDebugKotlin` 和 `build-playtv.ps1` 打包通过，APK 内播放 SDK 的双架构库核对通过；结构扫描无确定性违规。已在指定电视覆盖安装，返回 `Success`，普通入口启动返回 `Status: ok`，设备包信息可见内容服务。按用户要求未运行单元测试。三个入口顺序及导航、Activity 重建、未知动作、搜索返回、首次安装和覆盖更新后的授权与遥控操作尚未实测。

分享码入口变更：两端 Debug 包编译并在指定电视覆盖安装成功；通过首页焦点、方向键和确认键打开了 GenTV 的分享码输入页面。没有输入分享码或验证来源解析及播放；按用户要求未运行单元测试。
