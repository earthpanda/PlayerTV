# 已保存条目搜索

## 目标与范围

在现有 debug 播放源入口增加搜索，搜索已保存的每个来源的候选频道和影片，选择结果进入现有播放页并播放所选项。数据以历史存储的最后一次发现结果为准；每个来源最多 1000 项，部分来源可能不完整。搜索本身不搜索互联网或重新扫描来源；卡片图片按 [媒体资料与图片](media-metadata-artwork.md) 在可用时单独获取并保存在设备，缺失或失败时显示普通占位。

## 设计与交互

参考用户指定工程的实际搜索页：横屏左侧 6 列字母数字键盘、搜索内容展示及删除/清空，右侧四列结果；逐字更新、遥控器双向切换、选择播放、返回先清空再退出。顶部使用不可编辑的 TextView，不弹系统输入法；名称大小写不敏感匹配，也支持中文名称拼音和首字母（系统转写存在多音字限制）。保留各来源的相同名称，避免丢失不同播放地址。搜索结果先按来源最近使用顺序，再按来源原有顺序。搜索不到和历史读取失败分别提示；部分记录存在时提示搜索范围可能不完整。图片按原比例放入卡片，未取得时保留原占位。

## 数据契约与封装边界

历史存储 `SourceHistoryStore.state` 与 `load/find/open` 是搜索结果的唯一数据来源；条目和来源通过其 ID 关联，搜索不修改存储格式。model 中搜索 Contract 只提供来源 ID、条目 ID、显示名称和图片修订指纹，不向页面暴露地址。结果点击时再次检查来源及条目仍存在，成功后通过 ID 跳转；播放器按指定条目选择，未传条目 ID 时保留原先首项行为。图片按稳定 ID 访问独立存储，并可能发起受控网络请求；不新增后台服务、权限或依赖。已知受限标识使用项目规则的不可逆指纹过滤，语义与其他变体仍需后续核查。

## 生命周期与状态

搜索由页面 ViewModel 监听历史快照并在后台计算；后续输入替换旧计算。加载、失败、无记录、初始、无结果、结果及部分记录分别呈现；取消计算不改动历史，页面退出取消计算。输入与最近键盘焦点在配置变化后恢复；播放返回时保留搜索状态。图片任务绑定卡片，复用、回收或页面销毁时取消；具体边界和验收见媒体资料与图片文档。

## 变更影响与回归验证

改前首页为 debug 入口，历史选择进入播放器并默认选择第一项；播放器其他会话及播放/暂停、列表和手势逻辑不应变化。新增搜索入口与指定项播放；不改变历史内容及解析逻辑。用户确认参考逻辑宽度 1920，但项目公共横屏适配当前按短边解释该值，且现有所有预览界面和公共组件依赖未配置时的系统 dp 基线，直接设置会改变它们的尺寸。正式配置与全面迁移需结合公共基础和现有页面完成；本轮先保持配置，搜索实现为现有 debug 技术预览。

验证目标：字母、数字、中文与首字母匹配；重复名称、空/失败/部分记录；删除、清空、焦点往返和返回；选择非首项、失效项、播放器旧入口与返回；普通功能默认 3 个有效轮次。按项目授权边界本轮不主动编译、运行测试或安装，实际未验证项不得当作通过。
