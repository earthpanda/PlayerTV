# 已保存条目搜索

## 目标与范围

在现有 debug 播放源入口增加搜索，搜索已保存的每个来源的候选频道和影片，选择结果进入现有播放页并播放所选项。数据以历史存储的最后一次发现结果为准；每个来源最多 1000 项，部分来源可能不完整。搜索本身不搜索互联网或重新扫描来源；卡片图片按 [媒体资料与图片](media-metadata-artwork.md) 在可用时单独获取并保存在设备，缺失或失败时显示普通占位。

## 设计与交互

参考用户指定工程的实际搜索页：横屏左侧 6 列字母数字键盘、搜索内容展示及删除/清空，右侧四列结果；逐字更新、遥控器双向切换、选择播放、返回先清空再退出。顶部使用不可编辑的 TextView，不弹系统输入法；名称大小写不敏感匹配，也支持中文名称拼音和首字母（系统转写存在多音字限制）。保留各来源的相同名称，避免丢失不同播放地址。每次搜索先查开始时已完成拼音转换的条目，再查其余条目；各组内按来源最近使用顺序和来源原有顺序排列。同一次搜索及其分页使用固定分组，后台转换完成不会让条目在页间移动。搜索不到和历史读取失败分别提示；部分记录存在时提示搜索范围可能不完整。图片按原比例放入卡片，未取得时保留原占位。

## 数据契约与封装边界

历史存储 `SourceHistoryStore.state` 与 `load/find/open` 是搜索结果的唯一数据来源；条目和来源通过其 ID 关联。历史和派生搜索数据保存在同一个安装级私有 SQLite 数据库，使用系统 API，不增加数据库 SDK、注解处理或代码生成。model 中搜索 Contract 只提供来源 ID、条目 ID、显示名称和图片修订指纹，不向页面暴露地址。结果点击时再次检查来源及条目仍存在，成功后通过 ID 跳转；播放器按指定条目选择，未传条目 ID 时保留原先首项行为。图片按稳定 ID 访问独立存储，并可能发起受控网络请求；不新增后台服务或权限。已知受限标识使用项目规则的不可逆指纹过滤，语义与其他变体仍需后续核查。

## 生命周期与状态

搜索由页面 ViewModel 监听历史快照并在后台计算；后续输入替换旧计算。加载、失败、无记录、初始、无结果、结果及部分记录分别呈现；取消计算不改动历史，页面退出取消计算。输入与最近键盘焦点在配置变化后恢复；播放返回时保留搜索状态。图片任务绑定卡片，复用、回收或页面销毁时取消；具体边界和验收见媒体资料与图片文档。

历史首次读取或成功保存并发布后，应用进程内的搜索索引观察已提交快照，读取已持久化的拼音和检查结果，后台先为不同名称计算缺失的拼音和首字母，再计算缺失的名称检查结果；每 64 个名称一批提交数据库。同名共用计算，历史名称集合变化时取消旧准备并淘汰不再使用的名称。原始条目与待处理名称在同一数据库事务提交，后台结果只更新仍存在且版本匹配的名称；进程下次读取历史时恢复未完成项，不承诺进程结束后仍在后台执行。搜索与后台任务对同一名称的计算互斥；尚未完成的条目仍按需处理，检查失败不能当作通过。任务由 debug Application 组合根持有，不持有页面；页面退出只取消页面搜索。后台单项失败和两次持久化失败记录脱敏类型；未提交项保留待处理状态，下一次历史名称变化或进程重启时重新处理，不影响历史保存和播放。
