## 设计、承载与交互

用户截图是本轮播放页视觉参考，文字及普通 shape 为技术验证实现；未提供截图中的图标和正式画板宽度。debug Manifest 将启动入口切换到测试 Activity；release 继续保留原样例。Activity 横屏全屏显示，OK 播放/暂停，长按左右预览目标并在松开后定位；触摸画面可呼出控制层，水平滑动或拖动自定义进度条定位。SDK 状态为 PLAYING 且无选源解析或错误时，控制层在进入该状态或交互结束后 5 秒隐藏；暂停、准备、缓冲、结束、失败及来源解析期间保持显示，操作期间不隐藏。播放中打开列表可暂时隐藏控制层，列表关闭后重新计时；不可定位或时长未知时不发定位请求。遥控下键或画面向上滑动打开右侧半屏列表；列表打开时返回或点击列表外部关闭列表，关闭后返回退出页面。pt 宽度未配置，验证页仍使用系统基线，正式页面不猜测画板宽度。

初始化、准备、缓冲、播放、暂停、结束和失败由 SDK 状态映射；显示时间及错误。结束或失败可重新载入；播放器未就绪或不支持定位时禁用定位。页面后台暂停，不自动恢复；窗口销毁后解绑 Surface。

触摸播放/暂停文字复用同一播放事件；播放状态、错误和操作提示使用中英文资源。短按左右仅呼出控制层，不执行定位；定位预览不冒充已播放位置，取消或离页不提交。长按步长和触摸灵敏度是验证页实现参数，需设备体验后确认。

方向识别采用至少两倍系统 touch slop，且主方向位移至少为另一方向的 1.5 倍；未达到条件的斜滑不触发定位或列表，锁定后该次手势不再改变方向。向上滑打开列表，向下滑不打开。触摸方向计算需对应单测及设备复验，首个安装包尚未包含此调整。

播放列表仅展示用户输入并解析或从历史恢复的候选，不再内置默认片源。列表以焦点、已选和 SDK PLAYING 状态分别表达焦点、选中和正在播放；正在播放的名称允许跑马灯。请求被接受仅表示开始加载；实际播放以 SDK 状态为准。不同格式支持情况仍由能力侧验证，失败展示现有错误状态。选源和指定位置定位仅在 debug 验证页通过现有 SDK API 接入，双方后续接口及能力缺口见 [UI 与能力协作](../collaboration/player-ui-capability.md)。

## 首页左右布局（debug 技术验证）

用户要求参考 参考播放器 的主页，以左侧导航、右侧内容组织首页，仅设置“历史记录”和“视频源”两个 Tab，页面和交付信息不出现参考应用的品牌内容。只读查看参考源码及设备上的两种焦点状态：左侧获得焦点时菜单展开、当前项有蓝色高亮；焦点进入右侧后菜单收窄、当前项仍有选中标记；右侧空内容居中显示提示和操作入口。截图仅用于观察，不作为本项目设计资产或功能验收。

- **历史记录**：右侧展示已保存的播放来源，沿用最近使用时间倒序；选择一项进入播放页并加载该来源上次解析出的频道列表。空列表展示明确提示，可提供跳转“视频源”的入口。已有记录的读写失败保留错误提示，不以空列表掩盖。
- **视频源**：右侧展示地址输入、成功解析过的仓库地址建议及解析入口；保持现有的空输入、加载取消、限流与其他失败提示。发现首个候选后进入播放页并继续追加结果，解析成功的来源加入历史；不恢复已删除的默认来源。
- **遥控器与触摸**：默认选中“历史记录”；左侧上下移动焦点即切换右侧内容，右键或确认进入当前内容，内容区左键返回当前 Tab；地址输入框编辑和候选弹窗优先保留其自身的方向键行为。输入框获焦或再次确认时显示软键盘，失焦时收起；键盘显示时返回只收起键盘，保留焦点和内容。触摸可直接选择 Tab 和内容。焦点所在与当前选中分别可辨；输入联想、软键盘、返回、空列表和解析中等状态应保持可操作。页面重建恢复当前 Tab。
- **边界与复用**：优先沿用现有来源输入、历史列表、Loading、提示、解析会话与播放页面，播放器 SDK、解码和来源能力仍由对应能力侧负责。仅做主页与现有交互组合，不预设新增来源类型。
- **设计与验证**：参考图的颜色、留白和菜单收放是视觉方向，截图中的原尺寸不是本项目设计宽度。`design.width` 当前未配置，本次只调整已有 debug 技术页：使用文字 Tab、普通颜色和形状，侧栏收窄后仍保留完整名称，不引入图标或背景设计资产。正式页面需要明确画板宽度并按项目资产规则提供所需本地图标/背景。需验证两个 Tab 的焦点及返回、触摸、历史空/多条/失败、自动补全、解析中取消/失败、先有候选再追加和播放页往返；参考截图不等于本页验收。

## 数据契约与封装边界

2026-11-27 用户补充来源发现顺序：先按现有规则读取仓库 README 中明确的视频、播放列表和 JSON；再依次读取 README 内普通超链接指向的 HTTPS 页面或 GitHub 仓库，分析目标内容中的明确媒体、列表和 JSON，但不继续跟进这些目标中的普通超链接；随后执行原仓库文件树和网页 README 阶段。发现候选即可增量发布，不能中断当前播放；地址去重、数量、单次请求与总时限均有界，失败、超限或不完整时保留已发现项并标为部分结果。网页只解析静态文本和链接，不执行网页脚本；不直接把普通网页或仓库当作可播放视频。引用层数按用户最新说明为一层。历史打开先用已保存列表播放，同时后台以相同规则检查更新；用户确认完整扫描成功后删除来源中已消失的频道，失败、限流、超限、解析不完整或不能确认空结果时保留旧频道并合并新结果；不因此切换或停止当前播放。

当前实现待验证：一层普通链接最多 12 个、每个最多 5 秒、阶段最多 30 秒；原来源与链接页面各保留 8 次普通列表读取预算，JSON 沿用独立上限；链接到仓库时其扫描受该链接的时间限制。每来源总候选上限仍为 1000，超限和失败保留已有结果并标记部分。后台扫描由播放页持有，完成后由历史 Store 按快照和所有权检查写回；结果不完整时仅更新/追加，完整时替换。仅受支持规则范围内的扫描无失败才视为完整，不能证明未识别的外部格式不存在资源；没有可证实空结果的响应不清空历史。空 M3U、明确支持结构的空 JSON，以及完整仓库扫描中实际确认的空列表可以产生空历史项，重新打开后可继续扫描并手动选择新结果；旧版本仅接受非空历史项，降级时可能无法读取空历史，升级/降级兼容待验证。应用未在启动时自动扫描，页面退出时使刷新失效并取消。结构复核：来源读取和有界编排仍由既有 Repository 持有，URL 规则在 SourceRules，页面只管理页面内刷新和状态，历史 Store 负责写入及并发所有权。新增受控页面、仓库、空结果与合并用例；本轮没有编译、执行测试或安装设备，新增测试、旧来源、切源、并发与恢复等设备路径均待验证，不能视为完整验收。
